# Glossário (linguagem ubíqua)

| Termo | Significado no projeto |
|---|---|
| **Monograma** | Marca AM caligráfica aprovada. Ver `../10-dominio/objetos-de-valor/monograma.md`. |
| **V de Vida** | O V formado pela junção das pernas do A e do M; homenagem à cachorra Vida. |
| **Pombinha** | Leitura que emerge do topo das letras (paz/fé/bênção). |
| **Coroa** | Moldura orgânica do monograma (arco + ramo de eucalipto). |
| **Cabeçalho** | Bloco reutilizável (monograma + nomes) repetido nas brincadeiras. |
| **Brincadeiras** | Peças de papel interativas para os convidados (ex.: "Quem conhece melhor os noivos"). |
| **Evento 2026** | Celebração "falta 1 ano / 365 dias" em 01/08/2026. |
| **Casamento 2027** | O casamento em 01/08/2027. |
| **Mood v1** | Board de referência da cliente (≠ identidade final). |
