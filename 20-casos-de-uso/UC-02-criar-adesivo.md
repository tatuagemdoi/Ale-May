# UC-02 — Criar adesivo das caixas

- **Intenção:** adesivo para colar nas caixas de lembrança.
- **Composição:** **monograma + ramos + data 01/08/2027** (`datas.md` → casamento).
- **A definir:** o que cerca o monograma (ramo/eucalipto/moldura).
- **Restrições:** legível pequeno; 1 cor (tinta escura por ora); formato redondo/selo provável.
- **Saída:** arte vetor do adesivo (Claude Design).
